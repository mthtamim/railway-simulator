# Bangladesh Railway Pixel Simulator

A pixel-art train driving simulator on the Dhaka–Chattogram route (321 km, 29 stations) —
physics, passengers, timetable, scenarios and career mode in a single offline HTML file.

**Play: https://railway.mthtamim.bond**

Version: v3.7.2 · Single file, no build, no server needed — just open `index.html`.
By [mthtamim](https://github.com/mthtamim) · Home: https://mthtamim.bond
